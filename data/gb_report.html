6. Financial Interpretation

Feature Multicollinearity — What Was Dropped and Why

STOCK_RETURN_5DAY dropped — The 5-day return shares overlapping price data with the 1-day and 3-day return windows. More critically, it directly mirrors the prediction target (next-week direction), creating near-leakage. The model relies on shorter-window momentum and independent technical signals instead.

MA5 and MA10 dropped — Both encode the same concept: is price trending above its recent mean? They differ only in window length. Keeping both gives the model the same signal twice, inflating VIF without adding new information. ZSCORE is retained — it captures the same mean-deviation signal but normalizes by rolling volatility, making it scale-invariant across different price regimes.

PRICE_MA5_DIFF dropped — Redundant with ZSCORE. A raw dollar deviation of $5 is meaningless without knowing whether the stock trades at $50 or $500. ZSCORE corrects for this and is strictly more informative.

RELATIVE_STRENGTH dropped — Defined as NVDA 5-day return minus SPY 5-day return. Since SECTOR_RETURN_5DAY (XLK) is already in the feature set and XLK is heavily NVDA-weighted, both features measure market-relative outperformance with strong structural overlap. The sector-level signal is cleaner and less noisy.

Model Performance Analysis

ExtraTrees (AUC 0.676) — Best individual model. Extremely randomized trees split on random thresholds, which acts as aggressive regularization. This is ideal for financial features with fat-tailed distributions (OBV, volume) and low signal-to-noise. The randomization prevents overfitting to spurious threshold patterns that sequential boosting can latch onto.

GradientBoosting (AUC 0.609) — Sequential boosting captures hierarchical interactions: VIX regime signal interacts with SECTOR_RETURN before stock-level RSI and MACD become meaningful. This mirrors the top-down causal structure. Solid but slightly behind ExtraTrees due to higher variance on this dataset size.

RandomForest (AUC 0.600) — Comparable to GB. Bagging handles the noisy volume features (OBV, VOL_MA5) well by averaging over many trees. Trades some bias for stability, which is appropriate given only 386 training samples.

Stacking Blender (AUC 0.469 — below random) — Despite ExtraTrees replacing AdaBoost, the blender still underperforms. The issue is structural: with 386 training samples split across 5 OOF folds, each fold trains on ~309 samples and validates on ~77. The meta-features are noisy OOF estimates, and the blender has only 3 inputs — not enough signal for a GB blender to learn a reliable combination rule. A simpler blender (e.g. logistic regression or plain averaging) would likely outperform here.

Recommendation

The stacking framework is correct architecturally, but the dataset is too small (<400 training samples) for a learned blender to add value over simple averaging. With more data — either a longer historical window or higher-frequency data — the blender would have enough OOF signal to find a meaningful combination. For now, ExtraTrees alone (AUC 0.676) is the strongest predictor.
